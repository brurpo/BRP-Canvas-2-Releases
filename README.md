# BRP Canvas 2

[Download the portable Windows app](https://github.com/brurpo/BRP-Canvas-2-Releases/releases/latest).

Extract the small ZIP into its own writable folder and run **BRP.Canvas.exe**. The launcher installs the app, media tools, materials, brushes and HDRI collections from Google Drive, with download and installation progress. Everything stays in that portable folder; unchanged components are reused.

Models and AI runtimes download separately through the app. Application source is maintained in a separate private repository.
