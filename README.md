# BRP Canvas 2

[Download the portable Windows app](https://github.com/brurpo/BRP-Canvas-2-Releases/releases/latest).

Extract the ZIP into its own writable folder and run **BRP.Canvas.exe**, the main app. First-use setup installs media tools, HDRI environments, materials and brushes from Google Drive, with download and installation progress. Everything stays in the portable folder; unchanged resources are reused.

Models and AI runtimes download separately through the app. Application source is maintained in a separate private repository.
